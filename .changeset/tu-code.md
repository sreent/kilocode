Ship as TU Code: the `tucode` command and `@tucode/cli` package, and TU Code's name and icons in VS Code and JetBrains. There's no Kilo account sign-in, and no Kilo Gateway, cloud sessions, sharing, marketplace or product analytics: TU Code never connects to them. Settings live in `~/.config/tucode` and managed settings in `/etc/tucode`.
